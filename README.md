# Kezu

Avrupa'yı oyun gibi keşfettiğim uygulama: görev yap, XP kazan, yeni bölgeleri ve şehirleri aç.

- 4 şehir: Hamburg 🇩🇪, Berlin 🇩🇪, Kopenhag 🇩🇰, Amsterdam 🇳🇱 — 25 bölge, 182 görev (gez / ye / yap) + 48 mevsimlik etkinlik
- Şehirler toplam XP ile açılır ya da oraya gidip **pasaport damgası** basınca (konumla)
- Bölgeler o şehirde kazandığın XP ile sırayla açılır
- Konum doğrulama, vlog bonusu, günün görevi, haftalık seri, rozetler
- Her görevde o şehrin dilinde bir cümle (Almanca, Danca, Felemenkçe) — sesli okuma dahil
- Yemeklerde aşçı notu ve domuz uyarısı
- İnternetsiz çalışır (harita hariç), veriler sadece telefonda kalır

Yeni şehir eklemek: `cities.js` içinde `CITIES`, `REGIONS`, `QUESTS` ve `EVENTS` listelerine ekle.

Uygulama: https://nurikaradeniz.github.io/Kezu/
